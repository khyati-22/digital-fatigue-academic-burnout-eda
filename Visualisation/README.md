# Visualizations

This folder contains the visualizations generated during the Exploratory Data Analysis of the Digital Fatigue & Academic Burnout dataset.

The visualizations support the analysis by presenting patterns, distributions, comparisons, and relationships identified across different aspects of students' digital usage, digital fatigue, academic burnout, and well-being.

The visualizations are organized according to the major analysis sections of the project:

* Respondent Profile
* Digital Usage Analysis
* Digital Fatigue Analysis
* Academic Burnout & Well-being
* Relationship & Correlation Analysis

These visualizations were created using Python visualization libraries, primarily **Matplotlib** and **Seaborn**.
